# Why-Skill · 案件工作台

把一次归因分析变成一件可持久化的"案子"：事件材料 → 探针待办清单 → 现实查证 → 终极审计报告。

## 运行

```powershell
pip install streamlit openai httpx
python app.py    # 自动拉起 Streamlit
```

侧边栏填 API Key / Base URL / 模型（任意 OpenAI 兼容服务商）。案件数据存本地 `saves/cases/`，刷新不丢。

## 与 CLI 版（3.0）的区别

- **案件 = JSON 文件**：标题、问题、材料、每轮探针与思考、查证状态、补充记录、报告，整体落盘。
- **探针 = 待办清单**：按五节分组，可勾选 待查证/已查证/证伪，每条附查证结果；查证状态进入报告的证据强度。
- **多轮闭环**：补充后可"再出一轮探针"或"直接生成报告"；连续两轮无新探针或达上限（4 轮）时强制建议出报告。
- **省 token**：阶段二默认只发"事实卡 + 探针状态 + 补充"，不重发全文；侧边栏可切"完整模式"重发原文。
- 思考轮 + 成文轮兜底：思考完整收纳进案件，正文不因思考过长而截断。

`rules/` 为 3.0 规则文件的副本，改动时请同步两处。
