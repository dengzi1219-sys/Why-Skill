# 🕵️ Why-Skill 使用攻略：让 AI 帮你查"事情到底缺了什么"

> 真相永远在表层叙述之外。
> 很多人不是不会处理事情，而是**不知道自己缺了哪块信息**——工业故障、人际矛盾、历史疑案，大部分"想不通"都是信息不全，而当事人浑然不觉。

---

## 🧠 这是什么

一个「缺失信息优先」的归因审计工具：不猜结论，先帮你列出**"这件事还缺什么、该去查什么"**的探针清单，你查完回来，它再出终极审计报告。

## ✨ 三步用法

1. **建案**：粘贴事件材料（聊天记录 / 事件描述），可以附上你想搞清楚的问题
2. **探针待办**：AI 输出缺失信息探针清单（按物理/博弈/底噪/关键词/构造五类），每条都可以勾选「已查证 / 证伪」并写查证结果——比如"查生日转账金额""问对方当天行程"
3. **终极报告**：补充查证结果后，输出异常指数、事实与虚构拆解、根因推演（最可能→次可能→备选 + 置信度）、证据强度表、行动建议

查证过程可以**多轮**：补充后如果还有疑点，可以"再出一轮探针"，也可以直接出报告。

## 🌐 在线版 vs 💻 本地版（重要区别）

- **在线体验版**：打开即用、无需安装；但**没有存档**——刷新或休眠后案件不保留。所以：报告记得下载，探针清单可以导出 JSON，下次用「导入案件」续跑。
- **本地版**：下载项目后 `python app.py` 运行，案件存在自己电脑里，关浏览器、隔几天回来都还在，适合长期跟进一件事。

## 🔒 隐私与成本

- 自带 API Key，数据只发给模型服务商，Key 不落盘、不上传
- 成本极低：几万字的聊天记录分析，通常不到 1 元
- 模型可换：任意 OpenAI 兼容服务商（DeepSeek / OpenAI / Kimi / 通义 / GLM 都能用）

## 💡 小技巧

- 提问越具体，探针越准：比如"她为什么死守那个地方？"好过"分析一下"
- 探针是**待办清单**，不是废话——去问当事人、查记录、做个小实验，回来勾选
- 报告的证据强度会按你的查证状态自动调整：没查的标"待查证"，查了的进证据表
- 不确定的信息，报告会标注，绝不编造
